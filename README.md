# ITMO-3DCV
### Course 2025 | Yandex | School of Data Analysis

This repository contains my work from the ITMO 3D Computer Vision course. Each folder corresponds to a separate module or project from the course:

- [1_camera_calibration](./1_camera_calibration): Camera calibration techniques.
- [2_slam_from_scratch_(unfinished)](./2_slam_from_scratch_unfinished): SLAM implementation from scratch (incomplete).
- [3_differentiated_rasterization](./3_differentiated_rasterization): Differentiable rasterization methods.
- [4_nerf_from_scratch](./4_nerf_from_scratch): Neural Radiance Fields (NeRF) implementation from scratch.
